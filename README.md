# Генератор 3D-моделей с шумом Перлина

Генерация 3D-моделей для печати с внутренними полостями в виде сфер на основе шума Перлина.

## Требования

- Python 3.8+
- Виртуальное окружение (рекомендуется)

## Установка

### Windows

```bash
# Создание виртуального окружения
python -m venv venv

# Активация виртуального окружения
venv\Scripts\activate

# Установка зависимостей
pip install -r requirements.txt
```

### Linux/macOS

```bash
# Создание виртуального окружения
python3 -m venv venv

# Активация виртуального окружения
source venv/bin/activate

# Установка зависимостей
pip install -r requirements.txt
```

## Запуск

```bash
# Активируйте виртуальное окружение (если ещё не активировано)
# Windows:
venv\Scripts\activate
# Linux/macOS:
source venv/bin/activate

# Запуск генератора
python cheese.py
```

## Выходные файлы

- `example_YYYYMMDD_HHMMSS.stl` — 3D-модель в формате STL (имя содержит дату и время создания)

## Настройки

Основные параметры можно изменить в функции `main()`:

| Параметр | Описание | Значение по умолчанию |
|----------|----------|----------------------|
| `resolution` | Размер куба в вокселях | (100, 100, 100) |
| `voxel_size` | Размер одного вокселя в мм | 0.5 |
| `wall_thickness_mm` | Толщина внешних стенок в мм | 1.5 |
| `perlin_scale` | Частота шума Перлина (меньше = чаще экстремумы) | 15.0 |
| `max_radius_voxels` | Максимальный радиус сфер в вокселях | 12 |
| `overlap_factor` | Перекрытие сфер (0.35 = 35%) | 0.35 |
| `fill_threshold` | Порог заполнения (0.38 = 38% материала, 62% пустоты) | 0.38 |
| `max_attempts` | Максимум попыток генерации связной структуры | 15 |

## Особенности

- **Внешние стенки** — всегда сохраняются толщиной не менее 1.5 мм
- **Сферы внутри** — генерируются с отступом 2 вокселя от внешних стенок
- **Проверка связности** — алгоритм автоматически проверяет что внутренние пустоты образуют единый канал
- **Опоры для 3D печати** — добавляются под висящими частями модели
